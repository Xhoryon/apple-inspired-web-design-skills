# Apple Experience Skills v2.1.0

This release expands Visual Media and Cinematic Storytelling with a more flexible scene-based model for scroll-driven experiences.

## Highlights

- Scene Choreography beyond Hero-only animation.
- Scroll progress can drive horizontal motion, scale, depth, typography, layout, framing, and other scene changes.
- Cross-axis storytelling with explicit user-agency and anti-scroll-hijacking safeguards.
- Reversible narrative scene state while preserving user-owned state.
- Touch and narrow-screen adaptation may replace horizontal cinematic mechanics with clearer vertical editorial presentation.
- Video Semantic Conservatism for agents that cannot inspect video content.
- Opaque Media handling: technical availability does not imply semantic understanding.
- Clear separation between playback capability, cinematic suitability, and scroll-scrub suitability.
- Expanded Visual Media anti-pattern guidance.

Scene Choreography, Cross-Axis Storytelling, and Opaque Media are Skill-owned concepts, not official Apple terminology or requirements.
