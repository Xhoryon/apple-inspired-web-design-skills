# Professional Media Workflow

The Skill-owned Whole → Detail → Whole workflow for visual media composition. NOT Apple HIG canon.

## Workflow

```
Project intent
      ↓
Experience architecture
      ↓
Visual Experience Blueprint
      ↓
Media architecture (Media Role Contract per section)
      ↓
Asset audit (AVAILABLE / MISSING / UNKNOWN)
      ↓
Feasibility
      ↓
Section / app-state planning
      ↓
Detailed composition / Hero storyboard
      ↓
Experience prototype
      ↓
User review
      ↓
Revision
      ↓
Whole-experience review
      ↓
Detailed implementation
```

## Scope-Proportional Process

A small scoped request ("improve the image layout in this detail view") may proceed directly.

A whole-product / whole-site / cinematic-product experience requires broader intake:

- product purpose
- user task
- information architecture
- existing visual language
- target platforms
- available media
- brand assets
- content sequence
- implementation environment
- performance constraints
- required vs optional visual moments

## Visual Experience Blueprint dimensions

For a substantial project the Blueprint should describe the overall experience BEFORE detailed implementation. Possible dimensions:

- overall media tone
- light/dark progression
- visual density
- primary visual moments
- editorial vs cinematic balance
- interactive media locations
- narrative rhythm
- quiet / rest sections
- app working-media hierarchy
- expected platform adaptations

Good quality example (illustrative; do NOT copy as template):

> "Open with one restrained product-focused dark section, transition into lower-motion editorial media for feature explanation, reserve one interactive explorer for configuration, then return to a full-product conclusion rather than making every section cinematic."
