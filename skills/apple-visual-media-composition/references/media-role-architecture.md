# Media Role Architecture

The Media Role Contract is **Skill-owned Layer C vocabulary**, NOT Apple HIG canon.

## Media Role Contract

At minimum distinguish these roles:

- **Identity / Hero** — what the product / brand is.
- **Product proof** — what the product is / does.
- **Explainer** — why a feature matters.
- **Contextual / Lifestyle** — where / when / how the product fits.
- **Editorial** — narrative / story / thought.
- **Decorative / Atmospheric** — mood, texture, environment.
- **Application content** — content the user works with.
- **Preview** — quick confirmation without entering working context.
- **Inspection target** — careful examination of details.
- **Comparison target** — understanding differences.
- **Working content** — content the user is editing / manipulating.

## Media role affects

- scale (visual dominance)
- crop tolerance
- information fidelity requirement
- interaction
- prominence
- fallback

## Visual dominance

Ask: is media the argument, or evidence for text, or peer, or contextual? This informs size, placement, whitespace, crop, section height.

## Static / Editorial Mode (Mode A)

- large image
- split image / text
- editorial sequence
- evidence media
- full-bleed / contained media

## Interactive Media Explorer Mode (Mode B)

- color variants
- product variants
- feature controls
- material selection
- hotspots
- viewpoints
- before/after
- media-state driven explanation

## Cinematic Storytelling Mode (Mode C)

- Hero sequence
- sticky / pinned presentation
- scroll-linked state
- product / camera movement
- annotations
- narrative transitions

These three modes are distinct presentation modes. They are NOT an ordered maturity ladder. A design is not "better" because it reaches Cinematic.

## Application media modes

- **Browse** — find / recognize / navigate media.
- **Preview** — quick confirm without full working context.
- **Inspect** — careful examination.
- **Compare** — understand differences.
- **Work** — media is the work object.
