# Static Media Composition

## Large centered media

Possible structure:

```
headline / context
        ↓
    LARGE MEDIA
        ↓
supporting explanation
```

Appropriate when media deserves dominant attention. NOT mandatory.

## Split text / media

Examples:

```
TEXT        MEDIA
```

or

```
MEDIA       TEXT
```

## Hard rule

**Split layout does NOT mean automatic 50/50.**

Reason from:
- media importance
- text density
- subject position
- focal point
- available space
- reading sequence

## Full-bleed vs contained

Do NOT decide purely aesthetically. Reason from:

- media role
- fidelity requirement
- user task
- crop tolerance
- context
- available space

Examples:

- Atmospheric hero may be full-bleed.
- Inspection image may need complete bounds.
- Working canvas may use fit state.
- Preview may prioritize recognition.
