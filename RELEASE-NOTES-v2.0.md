# Apple Experience Skills v2.0.0

Apple Experience Skills v2.0.0 is a major evolution of the original Web-focused Skill pack into a broader professional experience-design system for AI coding agents.

## Highlights

- 13 primary Apple Experience Skills covering interaction, controls, pointer behavior, motion, navigation, direct manipulation, modality, advanced Liquid Glass, adaptive structure, feedback, keyboard and focus, text editing, and visual media.
- Platform-aware guidance spanning native Apple platforms and Web implementations without treating them as interchangeable.
- System-primitive-first decisions with explicit adaptation, approximation, fallback, and abandon paths.
- Capability and evidence safeguards that distinguish generation, inspection, runtime proof, metadata, and delegated evidence.
- Cross-cutting accessibility requirements for sensory alternatives, reduced motion, focus continuity, and adaptive structure.
- Seven established Web companion Skills retained for composition, visual foundations, components, Web materials, motion, routing, and auditing.

## Package

The public distribution contains the installable Skills, required Tier 2 references, the two cross-cutting contracts, README, release notes, and license. Development tests, evaluation suites, audit reports, source matrices, scanner tooling, screenshots, and internal logs are not distributed.

## Versioning

The internal v0.8 label identified the verified experimental architecture baseline. The public release is v2.0.0 because the project scope has expanded materially beyond the v1.1 Web-focused package.
